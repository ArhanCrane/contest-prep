# contest-prep
Preparing for Yandex Internship

Первая неделя:

1 день

- Теория:
    - скользящее окно;
- Практика (LeetCode):
    - 643 Maximum Average Subarray I;
    - 239 Sliding Window Maximum;        

2 день

- Теория:
    - битовые операции (XOR, AND, OR);
    - арифметика массивов (сумма, медиана).
- Практика (LeetCode):
    - 268 Missing Number;
    - 136 Single Number.

**Цель:** решить 4 задачи, понять шаблоны кода для скользящего окна и XOR.

3 день

- Теория:
    - жадные алгоритмы;
    - динамическое программирование (базовые случаи);
- Практика (LeetCode):
    - 322 Coin Change;
    - 518 Coin Change 2;

4 день

- Теория:
    - комбинаторика.
- Практика (LeetCode):
    - задачи на жадные стратегии (например, «Activity Selection»).

- Цель: освоить DP на примере «рюкзака», научиться выбирать жадные стратегии.

5 день

- Теория:
    - графы (BFS, DFS);
- Практика (LeetCode):
    - 733 Flood Fill;
    - 994 Rotting Oranges;

6 день

- Теория:
    - кратчайшие пути (Дейкстра).
- Практика (LeetCode):
    - 200 Number of Islands.

- Цель: научиться моделировать сетку как граф, применять BFS для поиска пути.

7 день

- Контест: выберите 3 задачи (1 Easy, 1 Medium, 1 Hard) из списка выше и решите их за 90 минут.
