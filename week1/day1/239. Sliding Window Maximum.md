239. Sliding Window Maximum
https://leetcode.com/problems/sliding-window-maximum/

## Статус: Изучена

## Условие:

Дан массив из N чисел и скользящее окно размера K, чья левая граница указывает на индекс 0.
Окно двигается каждый раз на один шаг, пока не дойдёт до индекса (K - 1).
Во время каждого шага числа в окне меняются, необходимо найти максимальные числа
из каждого нового окна, создав максимальное скользящее окно.

## Подход:

1 BruteForce O (N * k):

Окно всегда фиксированное (Fixed-Length Sliding Window).
Применяется цикл, который идёт от 0 до числа N (i < N). Каждую итерацию (i >= k - 1) создается новое окно, в котором
ведется поиск максимума за время O (k), где k - размер окна.

2 Optimal O (N) time:
Используется структура данных std::deque (dq) для хранения индексов неубывающих чисел.

- Итерируем через все числа от 0 индекса до числа N (i < N).
Последовательные операции в цикле:
  - Удаляем индексы чисел, которые выходят за рамки окна (dq.front() <= i - k)
  - Убираем числа из конца dq, если конечное число меньше или равно новому числу. В итоге индекс максимального числа в окне
  будет найден в начале очереди dq (dq.front())
  - Добавляется индекс нового числа в dq
  - Добавляется максимальное число в max_sliding_window
 
## Пример:
nums = [1,3,5], k = 2 \
deque<int> dq
vector<int> sl_win_max

Итерация 1 (i = 0, nums[i] = 1) \
  Если число в dq вышло за рамки окна (False) \
  Если число меньше следующего (False)

  Добавление числа (True) \
  //    1 \
  dq = {0}
  
  Если окно имеет размер K (False)

Итерация 2 (i = 1, nums[i] = 3) \
  Если число в dq вышло за рамки окна (False) \
  Если число меньше следующего (True) \
  dq = {}

  Добавление числа (True) \
  //    3 \
  dq = {1}
  
  Если окно имеет размер K (True) \
  sl_win_max = {3}

Итерация 3 (i = 2, nums[i] = 5) \
  Если число в dq вышло за рамки окна (False) \
  Если число меньше следующего (True) \
  dq = {}

  Добавление числа (True) \
  //    5 \
  dq = {2}
  
  Если окно имеет размер K (True) \
  sl_win_max = {3, 5}


## Краевые случаи:

K = 1: Цикл отработает верно, отправит индекс в dq, который сразу отправится в результат
K = N: Цикл будет сортировать числа в dq, а перед выходом на последней итерации занесет число в результат

## Сложность по скорости: O (N)

Один цикл, который отработает N раз. Операции push_back, pop_front(), pop_back() работают за О (1).

## Сложность по памяти: O (K)

max_sliding_window будет хранить (N - K) чисел. 
В dq хранится K чисел.

## Код:

```c++
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        const int n = static_cast<int>(nums.size());
        std::vector<int> max_sliding_window;
        std::deque<int> dq;

        for (int i{}; i < n; i++) {
            if (!dq.empty() && dq.front() <= i - k) {
                dq.pop_front();
            }
            while (!dq.empty() && nums[dq.back()] <= nums[i]) {
                dq.pop_back();
            }
            dq.push_back(i);
            if (i >= k - 1) {
                max_sliding_window.push_back(nums[dq.front()]);
            }
        }

        return max_sliding_window;
    }
};
```
