136 Single Number \
https://leetcode.com/problems/single-number/description/

## Статус: Решена с подсказкой за 20 минут

## Условие:

Дана нечетная последовательность чисел. Каждое число встречается ровно два раза,
кроме одного, которое находится в единственном экземпляре. Нужно найти такое число.

## Подход:

Использование оператора XOR.

время: O (N), линейный проход через все элементы массива\
память: O (1)
 
## Пример:

```
[4, 1, 2, 1, 2]

int num = 0;
for loop (0 to N) {
  //Итерация 1 - num = num ^ nums[i] //num = 0 ^ 4 = 4
  //Итерация 2 - num = num ^ nums[i] //num = 4 ^ 1 = 5
  //Итерация 3 - num = num ^ nums[i] //num = 5 ^ 2 = 7
  //Итерация 4 - num = num ^ nums[i] //num = 7 ^ 1 = 6
  //Итерация 5 - num = num ^ nums[i] //num = 6 ^ 2 = 4
}

//Результат: 4

/*
a ^ b = b ^ a (коммутативность)
(a ^ b) ^ c = a ^ (b ^ c) (ассоциативность)
a ^ a = 0
a ^ 0 = a

4 ^ 1 ^ 2 ^ 1 ^ 2 = 4 ^ (1 ^ 1) ^ (2 ^ 2) = 4 ^ 0 ^ 0 = 4
*/

```

## Краевые случаи:

По условию последовательность не меньше 1. Оператор XOR
справится с любыми числами в диапазоне от ```(-3*10^4 to 3*10^4)```

## Код:

```c++
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        const int n = static_cast<int>(nums.size());

        int number = 0;
        for (int i{}; i < n; i++) {
            number ^= nums[i];
        }

        return number;
    }
};
```
