268 Missing Number \
https://leetcode.com/problems/missing-number/description/

## Статус: Решена

## Условие:

Дан массив размером N, в котором только уникальные числа в диапазоне от 0 до N.
Необходимо найти число, которого не хватает в контейнере.
N >= 1

## Подход:

Формула арифметической прогрессии:
```math
sum = n * (n + 1) / 2
```
Необходимо отнять от суммы всех чисел, включая пропавшее, от сложения имеющихся цифр в массиве.

время: O (N) \
память: O (1)
 
## Пример:
```
nums[0, 1, 2, 3, 4] N = 5
sum = 5 * (5 + 1) / 2 = 15

for (i, from nums[0] to nums[N - 1]) {
  //Итерация 1
  sum = 15 - 0

  //Итерация 2
  sum = 15 - 1

  //Итерация 3
  sum = 14 - 2

  //Итерация 4
  sum = 12 - 3

  //Итерация 5
  sum = 9 - 4

  //Ответ:
  sum = 5
}

```
## Краевые случаи:

N >= 1, потому N не может быть нулём.

В случае [1, 2, 3, 4, 5], ответом будет число ноль, что является правильной работой программы

## Код:

```c++
class Solution {
public:
    int missingNumber(vector<int>& nums) {
        //Arithmetic Progression - (n * (n + 1) / 2)
        const int n = static_cast<int>(nums.size());
        //range is from 0 to n
        int sum = n * (n + 1) / 2;
        for (const auto& elem : nums) {
            sum -= elem;
        }
        
        return sum;
    }
};
```
