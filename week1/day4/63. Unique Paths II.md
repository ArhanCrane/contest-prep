63 Unique Paths II \
https://leetcode.com/problems/unique-paths-ii/description/

## Статус: Изучена

## Условие:

Дано поле m * n. Робот, стоящий в левой верхней клетке должен дойти \
до правой нижней. Необходимо посчитать количество путей от начальной \
точки до конечной. Однако на поле расположены стены, преграды, через \
которые нельзя проходить.

## Подход: 

Динамическое программирование:

Скорость: O (m * n)
Память: O (n)

## Пример:
```
obstacle = [
  0, 0, 0
  0, 1, 0 //1 - преграда, тупик
  0, 0, 0
]

Имеется массив dp размера n = {1, 0, 0}

Цикл 1 от 0 до m (i):
  Цикл 2 от 0 до n (j):
  // По выходу из Цикла 2 (i = 0) - dp = {1, 1, 1}
  // По выходу из Цикла 2 (i = 1) - dp = {1, 0, 1}
  // По выходу из Цикла 2 (i = 2) - dp = {1, 1, 2}

Результат: dp[n-1] = 2
```

## Краевые случаи:

По условию поле не может быть 0 x 0 (пустым).

## Код:

```c++
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        const int m{static_cast<int>(obstacleGrid.size())};
        const int n{static_cast<int>(obstacleGrid[0].size())};        
        if (obstacleGrid[0][0]) {
            return 0;
        }

        vector<int> dp(n, 0);
        dp[0] = 1;

        for (int i{}; i < m; i++) {
            for (int j{}; j < n; j++) {
                if (obstacleGrid[i][j]) {
                    dp[j] = 0;
                }else if (j > 0) {
                    dp[j] += dp[j-1];
                }
            }
        }

        return dp[n-1];
    }
};
```
