62 Unique Paths \
https://leetcode.com/problems/unique-paths/description/

## Статус: Решена за 5 минут

## Условие:

Робот стоит в левом верхнем углу площадки размером m * n клеток. \
Нужно посчитать количество путей (комбинаций), следуя которым \
робот попадет в правый нижний угол. Двигаться робот может только вниз или вправо.

## Подход: 

A. Динамическое программирование. O (m * n), O (m * n) (База, 2D)
Создается двумерный массив dp (m * n). Все значения по умолчанию 1.
Используем два цикла:
1. В диапазоне от 1 до m (i >= 1);
  2. В диапазоне от 1 до n (j >= 1);
     dp[i][j] = dp[i-1][j] + dp[i][j-1]

B. Динамическое программирование. O (m * n), O (n) (Оптимизированный вариант, 1D, хотя итерировать надо со сложностью O (m*n))
Создается одномерный массив dp (n). Все значения по умолчанию 1.
Используем два цикла:
1. В диапазоне от 1 до m (i >= 1);
  2. В диапазоне от 1 до n (j >= 1);
     dp[i] += dp[i-1];
     
C. Комбинаторика. ```O (min(m*n)), O(1)```
Каждый вариант пройти из точки А в точку В - сочетание ходов, формула из комбинаторики. \
Роботу нужно сделать m-1 шагов вниз (D) и n-1 шагов вправо (R). \
Есть масса вариантов:
- DDRRRRR (сделать два шага вниз, а затем пять шагов вправо)
- RRRDRRD (шагнуть вправо три раза, потом вниз, затем снова два раза вправо и закончить шагом вниз)

Это и есть сочетания, которые находятся формулой комбинаторики: \
Формула сочетаний: 
```math 
C(n, k) = n! / (k! * (n - k)!)
```
Где n - общее количество ходов, а k - число (m или n)
Разберём два варианта:
1. С(m + n - 2, m-1) = m+n-2! * (m-1! * (m+n-2-m-1)!) = m+n-2! * (m-1! * n-1!) - В последней скобке просто два числа (m-1) и (n-1)
2. С(m + n - 2, n-1) = m+n-2! * (n-1! * (m+n-2-n-1)!) = m+n-2! * (n-1! * m-1!) - В последней скобке также два числа (n-1) и (m-1), перестановка не меняет результат

## Пример:

1. total = m + n - 2
2. k = min(m-1, n-1)

k = min(2, 6) = 2

result = 1;

/*
for (0 to k) (i) // (0 to 2)
  result = result * (total - i) / (i + 1)
*/

На второй итерации: result = 8 * (8 - 1) / (1 + 1) = 8 * 7 / 2 = 28

Результат - 28

## Код:

```c++
//C
class Solution {
public:
    int uniquePaths(int m, int n) {
        int total = m + n - 2;
        int k = std::min(m-1, n-1);
        long long answer{1};
        
        for (int i{}; i < k; i++) {
            answer = (answer * (total - i)) / (i + 1);
        }
        return answer;
    }
};
//B
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);
        for (int i{1}; i < m; i++) {
            for (int j{1}; j < n; j++) {
                dp[j] += dp[j - 1];
            }
        }
        return dp[n-1];
    }
};
//A
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n, 1));
        for (int i{1}; i < m; i++) {
            for (int j{1}; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m-1][n-1];
    }
};
```
