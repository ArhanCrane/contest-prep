605 Can Place Flowers \
https://leetcode.com/problems/can-place-flowers/description/

## Статус: Изучена

## Условие:

Есть цветочный сад из нулей и единиц. Единица может стоять только вокруг нулей [0,1], [1,0], [0,1,0]. \
Необходимо вернуть значение (true, false), если можно разместить N-ое количество единиц, при этом не нарушая
правила размещения (единицы окружены нулями).

## Подход:

Жадный алгоритм

Перебор всех чисел. На каждой позиции проверяем, чтобы \ 
предыдущее число и следующее были равны нулям или стенкам (выходам за пределы массива).

Время: O (N) \
Память: O (1)

## Краевые случаи:

n = 0
+ 1. [1], n = 0
+ 2. [0,1], n = 0
+ 3. [1,0], n = 0
+ 4. [0,1,0], n = 0
+ 5. [1,0,1], n = 0
+ 6. [0,0,0], n = 0
+ 7. [1,0,0,0], n = 0
+ 8. [0,0,0,1], n = 0
+ 9. [0,0,0,0,0], n = 0
+ 10. [1,0,0,0,1], n = 0

## Код:

```c++
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        const int m = static_cast<int>(flowerbed.size());

        for (int i{}; i < m; i++) {
            bool left = (i == 0 || flowerbed[i-1] == 0);
            bool right = (i == m - 1 || flowerbed[i+1] == 0);
            if (left && right && flowerbed[i] == 0) {
                n--;
                flowerbed[i] = 1;
            }
        }
        return n <= 0;
    }
};
```
