455 Assign Cookies
https://leetcode.com/problems/assign-cookies/description/

## Статус: Решена за 10 минут

## Условие:

Родитель хочет дать печенье своим детям. Каждый ребенок
имеет фактор "жадности" (g[i]), а каждое печенье имеет вес (s[i]).
Ребенок считается довольным, если размер/вес печенья покрывает его фактор (s[i] >= g[i]).
Нужно вернуть максимальное число довольных детей.

## Подход: 

Жадный алгоритм.

1. Необходимо отсортировать массив (g) с факторами "жадности" детей и массив (s) с размерами печенья.
2. Есть два указателя (content_childen) и (j). Первый указатель смотрит на g, а второй на s.
3. Мы двигаем j пока не найдется условие, при котором ребенок будет удовлетворен, или пока j не доайдет до конца s.

Время: O (n)
Память: O (1)

## Код:

```c++
class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        const int m = static_cast<int>(g.size());
        const int n = static_cast<int>(s.size());
        
        std::sort(g.begin(), g.end());
        std::sort(s.begin(), s.end());
        
        int content_children{}, j{};        
        while (content_children < m && j < n) {
            if (g[content_children] <= s[j]) {                
                content_children++;
            }
            j++;     
        }
        return content_children;
    }
};
```
