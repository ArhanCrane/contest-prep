70 Climbing Stairs \
https://leetcode.com/problems/climbing-stairs/description/

## Статус: Решена/Изучена

## Условие:

Есть лестница из n ступенек. Можно перешагивать через одну или через две ступеньки за раз.
Нужно узнать, сколько есть различных способов добраться до вершины.

## Подход: 

1. Динамическое программирование:
n = 3
stairs = {1, 1, 0, 0} //Массив размером N+1, чтобы избежать риска выхода за пределы массива в цикле. \
На первой ступени гарантированно будет один способ.

В цикле от 2 до N (i): обращаемся к ячейкам i-2 и i-1
  stairs[i] = stairs[i-2] + stairs[i-1]

Скорость: O (n)
Память: O (n)

2. Числа Фибоначчи
Каждое последующее число в массиве из динамического программирования равнялось двум предыдущим.

Скорость: O (n)
Память: O (1)

## Код:

```c++
//1. DP
class Solution {
public:
    int climbStairs(int n) {
        int ans;
        vector<int> dp(n+1, 1);                
        for (int i{2}; i <= n; i++) {
            dp[i] = dp[i-1] + dp[i-2];
        }
        ans = dp[n];
        return ans;
    }
};
```
```c++
//2. Fibonacci Numbers
class Solution {
public:
    int climbStairs(int n) {        

        int prev1{1};
        int prev2{1};                     

        for (int i{2}; i <= n; i++) {
            int Fibonacci = prev1 + prev2;
            prev1 = prev2;
            prev2 = Fibonacci;
        }
        
        return prev2;
    }
};
```
