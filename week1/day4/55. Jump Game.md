55 Jump Game \
https://leetcode.com/problems/jump-game/description/

## Статус:

## Условие:

Дан массив из N чисел. Каждое число представляет максимально допустимую длину шагов.
Мы находимся в позиции 0. Надо вернуть true, если можно дойти до позиции (N - 1).

## Подход: 
Динамическое программирование
Имеется переменная lastIndex = 0, которая сообщает, до какого индекса можно добраться \
В цикле от (0 до N) проверяется каждое число, при этом обновляется
lastIndex.

Время: O (N)
Память: O (1)
 
## Пример:

```
[2,3,1,1,4]
lastIndex = 0;

Цикл for (i):
  //Итерация 1:
    Если i <= lastIndex: lastIndex = min(lastIndex, текущий индекс плюс максимальное число шагов)
      lastIndex = 2
  //Итерация 2:
    Если i <= lastIndex: lastIndex = min(lastIndex, текущий индекс плюс максимальное число шагов)
      lastIndex = 4
      Если lastIndex >= n: break;

return lastIndex >= N;
```

## Краевые случаи:

```1. [2,3,1,1,4] ```
```2. [3,2,1,0,4] ```
```3. [0] ```
```4. [0,1] ```

## Код:

```c++
class Solution {
public:
    bool canJump(vector<int>& nums) {
        const int n = static_cast<int>(nums.size());
        int lastIndex = 0;
        
        for (int i{}; i < n; i++) {
            if (i <= lastIndex) {
                lastIndex = std::max(lastIndex, i + nums[i]);
                if (lastIndex >= n - 1) {
                    break;
                }
            }
        }
        return lastIndex >= n - 1;
    }
};
```
