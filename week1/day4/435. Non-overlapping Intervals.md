435 Non-overlapping Intervals \
https://leetcode.com/problems/non-overlapping-intervals/description/

## Статус: Решена

## Условие:

Даны отрезки, которые могут пересекаться. Необходимо удалить \
наименьшее число отрезков, чтобы все остальные стали непересающимися.

Условие, при котором два отрезка p1(start, end), p2(start, end) не пересекаются: p2.end <= p3.start.

## Подход: 

Жадный алгоритм:
- Сортировка начала
1. Сортировка отрезков по началу.
2. Обновление текущего отрезка при условии, что curr.end <= intervals[i].start или, если curr.end > intervals[i].start и curr.end > intervals[i].end.
3. При пересечении отрезков обновляется счет удаленных отрезков.

- Сортировка конца
1. Сортируем отрезки по концам.
2. Заводим переменную prev_end, хранящую конец первого отрезка.
3. При переборе всех отрезков инкрементируем переменную удаленных, если prev_end > intervals[i].start.
4. Если prev_end <= intervals[i].start, обновляем конец prev_end на intervals[i].end.

Время: O (nlogn)
Память: O(1) - Память не зависит от увеличения числа N, только счетчик и одна переменная

## Код:

```c++
//Сортировка начала
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        int intervals_num{};
        std::sort(intervals.begin(), intervals.end(), [](const auto& p1, const auto& p2) {return p1[0] < p2[0];});
        std::vector<int> curr = intervals[0];

        for (int i{1}; i < intervals.size(); i++) {
            if (curr[1] > intervals[i][0]) {
                if (curr[1] > intervals[i][1]) {
                    curr = intervals[i];
                }
                intervals_num++;                
            }else {
                curr = intervals[i];
            }
        }

        return intervals_num;
    }
};
```

```c++
//Сортировка конца
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        int intervals_num{};
        std::sort(intervals.begin(), intervals.end(), [](const auto& p1, const auto& p2) {return p1[1] < p2[1];});
        int prev_end = intervals[0][1];

        for (int i{1}; i < intervals.size(); i++) {
            if (prev_end > intervals[i][0]) {
                intervals_num++;
            }else {
                prev_end = intervals[i][1];
            }
        }

        return intervals_num;
    }
};
```
