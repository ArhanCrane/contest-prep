518 Coin Change II \
https://leetcode.com/problems/coin-change-ii/description/

## Статус: Изучена

## Условие:

Дан массив с денежными значениями монет и определенная сумма. Необходимо
найти количество способов получить сумму (amount).

## Подход: 

Динамическое программирование (Dynamic Programming);


время: O (coins.size * amount); Перебор цикла в цикле.
память: O (amount); Хранение одномерного массива.

## Оптимальный пример

```
coins = [1, 2, 5], amount = 5

dp = {
  1, 0, 0, 0, 0, 0
}

//dp после отработки цикла
dp = {
  1, 1, 2, 2, 3, 4
}

Результат: dp[coins.size][amount] = 4

//Структура цикла
for loop (from 1 to coins.size)
  for loop (from coin to amount + 1)
    //Если монета меньше или равна сумме
    dp[j] += dp[j - coin]
```

## Краевые случаи:

При amount == 0 и coins.size == 1 программа выдаст 1

## Код:

```c++
class Solution {
public:
    int change(int amount, vector<int>& coins) {
        const int n = static_cast<int>(coins.size());
        vector<unsigned int> dp(amount + 1, 0);
        dp[0] = 1;

        for (int i{1}; i <= n; i++) {
            for (int j{coins[i-1]}; j <= amount; j++) {
                dp[j] += dp[j - coins[i-1]];
            }
        }

        return dp[amount];
    }
};
```
