200 Number of Islands \
https://leetcode.com/problems/number-of-islands/

## Статус: Решена

## Условие:

Есть сетка размера (M * N), в которой число 1 - суша, а 0 - вода. \
Нужно вернуть число островов на карте.

Остров окружен водой и состоит из соединенных горизонтальных \
и вертикальных чисел 1.

## Подход:

Поиск в ширину (BFS - breath-first search)

1. Создаем счетчик островов и массив, содержащий направления (лево, право, верх, низ)
2. Цикл, идущий от нуля до числа M
3. Цикл диапазона от нуля до числа N
4. Проверка, если число равно 1
5. Инкрементировать счетчик островов. Пометить клетку, как посещенную (сделать равной нулю)
6. алгоритм перебора всех точек вокруг найденной единицы (bfs)
7. вернуть счет островов

Время: O (M * N)
Память: O (M * N)

## Код:

```c++
class Solution {
public:
    int numIslands(vector<vector<char>>& grid) {
        const int m = static_cast<int>(grid.size());
        const int n = static_cast<int>(grid[0].size());

        int cnt_islands{};
        vector<pair<int, int>> dirs = {
            {-1, 0}, {1, 0}, {0, -1}, {0, 1}
        };
        for (int i{}; i < m; i++) {
            for (int j{}; j < n; j++) {
                if (grid[i][j] == '1') {
                    cnt_islands++;
                    grid[i][j] = '0';
                    queue<pair<int, int>> local_q;
                    local_q.push({i, j});
                    while (!local_q.empty()) {
                        auto [x, y] = local_q.front();                        
                        local_q.pop();
                        for (auto [dx, dy] : dirs) {
                            int x_new = x + dx;
                            int y_new = y + dy;
                            if (x_new >= 0 && x_new < m && y_new >= 0 && y_new < n && grid[x_new][y_new] == '1') {
                                grid[x_new][y_new] = '0';
                                local_q.push({x_new, y_new});
                            }
                        }
                    }
                }
            }
        }
        return cnt_islands;
    }
};
```
