994 Rotting Oranges \
https://leetcode.com/problems/rotting-oranges/description/

## Статус: Изучена

## Условие:

Есть поле размером M * N из чисел (0, 1, 2). \
0 - пустое поле \
1 - свежий апельсин \
2 - гнилой апельсин \
Каждую минуту свежие апельсины рядом с гнилыми будут портиться, обращаясь из 1 в 2. \
Необходимо вычислить количество минут, за которое все свежие фрукты испортятся.

## Подход: 

Поиск в ширину (bfs - breath-first search).

1. Создается массив посещенных клеток
2. Инициализируется очередь для хранения гнилых апельсинов и подсчета свежих
3. Проверяется, если нет свежих апельсинов, то ответ 0, а если очередь пуста, то ответ -1
4. Проходим по всей очереди, пока она не пуста
    a. Хранится размер очереди
    b. Цикл, проходящий через размер очереди
        - Берется первый элемент в очереди
        - Проверяются все точки относительно текущей (правая, левая, верхняя, нижняя)
        - Если точка - свежий апельсин (1), то меняется значение на гнилой (2), счетчик свежих апельсинов \
          уменьшается, а индексы точки отправляются в очередь
    c. Увеличить число минут на один
5. Если нет свежих апельсинов, возвращаем минуты
6. Если всё ещё есть свежие, то возвращаем -1

Время: O (m * n)
Память: O (m * n)

## Код:

```c++
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        const int m = static_cast<int>(grid.size());
        const int n = static_cast<int>(grid[0].size());

        std::queue<std::pair<int, int>> q;
        int cntFresh{};

        std::vector<std::vector<int>> visited = grid;
        for (int i{}; i < m; i++) {
            for (int j{}; j < n; j++) {
                if (visited[i][j] == 2) {
                    q.push({i, j});
                }
                if (visited[i][j] == 1) {
                    cntFresh++;
                }
            }
        }

        if (cntFresh == 0) {
            return 0;
        }
        if (q.empty()) {
            return -1;
        }

        int minutes{-1};
        std::vector<std::pair<int, int>> dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        while (!q.empty()) {
            int q_size = static_cast<int>(q.size());
            while (q_size--) {
                auto [x, y] = q.front();
                q.pop();
                for (auto [dx, dy] : dirs) {
                    int i = x + dx;
                    int j = y + dy;
                    if (i >= 0 && i < m && j >= 0 && j < n && visited[i][j] == 1) {
                        visited[i][j] = 2;
                        q.push({i, j});
                        cntFresh--;
                    }
                }
            }
            minutes++;
        }
        if (cntFresh != 0) {            
            return -1;
        }
        return minutes;
    }
};
```
